# Phase 7 - Project Documentation

## Project Name
EduGenie: Google Gemini Powered Learning Assistant

## Technology Stack
- Python
- FastAPI
- HTML
- CSS
- JavaScript
- Google Gemini API

## Modules
1. Q&A
2. Topic Explanation
3. Quiz Generator
4. Notes Summarizer
5. Learning Path Generator

## API Endpoints
- GET `/api/health`
- POST `/api/qna`
- POST `/api/explain`
- POST `/api/quiz`
- POST `/api/summarize`
- POST `/api/learning-path`

## Security
The Gemini API key is stored in `.env` and should not be committed to source control.
