# Phase 1 - Brainstorming & Ideation

## Project Title
EduGenie: Google Gemini Powered Learning Assistant

## Problem Idea
Students often need quick explanations, answers, summaries, quizzes, and structured study plans in one place.

## Proposed Solution
EduGenie is a web-based AI learning assistant that uses Google Gemini to provide:
- Question and Answer
- Topic Explanation
- Quiz Generation
- Notes Summarization
- Personalized Learning Path

## Objectives
1. Provide a simple student-friendly learning interface.
2. Generate clear educational answers.
3. Help students revise through quizzes and summaries.
4. Create structured study plans.
5. Keep all learning tools in one application.
